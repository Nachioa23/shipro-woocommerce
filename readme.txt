Cotización, etiquetas y seguimiento de envíos con Shipro (multicourier Argentina).

== Description ==

Conectá tu tienda WooCommerce con Shipro para cotizar precios de envío, generar
etiquetas y rastrear paquetes con múltiples couriers argentinos desde un solo panel.

Este skeleton (v0.1.0) sólo instala la conexión: pegás tu API Key de Shipro en
**WooCommerce > Ajustes > Shipro**. La cotización en checkout, la generación de
etiquetas y el rastreo se agregan en versiones siguientes.

Requiere WooCommerce activo. Compatible con HPOS (High-Performance Order Storage)
y con el Cart & Checkout Blocks.

== Installation ==

1. Subí el zip del plugin desde **Plugins > Añadir nuevo > Subir plugin**.
2. Activá el plugin.
3. Andá a **WooCommerce > Ajustes > Shipro** y pegá tu API Key.
